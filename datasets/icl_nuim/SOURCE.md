Local derivatives: every fifth RGB/depth frame extracted; positive-fy OpenCV camera convention recorded; RGB sequence encoded as an MP4; a 45-image subset copied for the photo experiment; inferred plans and diagnostic plots generated by this repository. Reference mesh dimensions are read only during evaluation of the automatic RGB-D branch. A separate oracle benchmark samples the named wall mesh and adds simulated noise; it is labelled accordingly.

This is synthetic RGB-D data. It is not a phone LiDAR capture. Its single-room reference does not evaluate multi-room stitching, and passing it would not establish field accuracy.
